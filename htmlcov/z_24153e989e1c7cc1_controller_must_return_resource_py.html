14class ControllerMustReturnResource(Rule): 

15 """ 

16 Regra arquitetural: 

17 

18 SOLAR-ARCH-014 

19 

20 Todo Controller deve retornar uma resposta que tenha passado por 

21 um Resource. 

22 

23 Fluxo exigido: 

24 

25 Controller → Resource → Response 

26 

27 É VIOLAÇÃO: 

28 

29 class UserController: 

30 

31 @staticmethod 

32 def show(): 

33 return {"id": 1, "name": "Ana"}, 200 

34 

35 Correto: 

36 

37 class UserController: 

38 

39 @staticmethod 

40 def show(): 

41 return UserResource.to_object(user), 200 

42 

43 O que a regra procura é a CHAMADA ao Resource (`to_object` para 

44 um item, `collection` para uma lista): quem monta a representação 

45 da resposta é o Resource, e chamá-lo é o que tira do Controller a 

46 decisão do que sai. 

47 

48 O motivo é o de sempre: sem o Resource, um campo interno 

49 (`password`, `secret_key`, um token) nasce exposto por descuido, e 

50 o cliente passa a depender dele. Quem decide o que é público é o 

51 Resource — e é a SOLAR-ARCH-021 que julga o que ele expõe. 

52 

53 Diferente das regras de dependência (SOLAR-ARCH-001 a 012), esta 

54 NÃO valida o grafo de imports. O contexto dela é o RETORNO de um 

55 método de Controller. 

56 """
