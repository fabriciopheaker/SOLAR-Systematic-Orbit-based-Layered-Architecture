1# Contexto da SOLAR-ARCH-027: um uso de JWT/Token no código. 

2# 

3# Os campos anuláveis são o ponto: `None` significa "o scanner não 

4# conseguiu ver", e não "está errado" nem "está certo". A regra 

5# acusa só o que foi VISTO errado — acusar a dúvida daria falso 

6# positivo em token montado em tempo de execução. 

7from dataclasses import dataclass 

8 

9 

10@dataclass(frozen=True) 

11class TokenUsage: 

12 """ 

13 Descreve um uso de JWT/Token encontrado no código-fonte. 

14 

15 operation: 

16 "encode" (emissão) ou "decode" (leitura). 

17 

18 algorithm: 

19 Algoritmo declarado, quando informado. 

20 None quando não foi declarado explicitamente. 

21 

22 verifies_signature: 

23 Para "decode": False quando a verificação de assinatura 

24 foi desativada. None quando não há informação. 

25 

26 has_expiration: 

27 Para "encode": False quando o payload não declara "exp". 

28 None quando o payload não é um literal (não verificável). 

29 

30 file / line: 

31 Onde o uso aparece. 

32 """ 

33 

34 operation: str 

35 

36 # Tri-estado nos três: `None` é "não verifiquei", `False` é 

37 # "verifiquei e está errado". A regra só acusa o `False`. 

38 algorithm: str | None 

39 verifies_signature: bool | None 

40 has_expiration: bool | None 

41 

42 file: str 

43 line: int
