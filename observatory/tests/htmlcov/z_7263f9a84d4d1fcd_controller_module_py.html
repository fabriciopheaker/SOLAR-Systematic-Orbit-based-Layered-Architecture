1# Onde mora o módulo de um Controller. 

2# 

3# Compartilhado pelas regras que falam de Controller — 014, 022, 025 e 

4# 026 —, porque as quatro precisam CONCORDAR sobre o que é um 

5# Controller: uma peça que é Controller para uma regra e não é para 

6# outra produz exatamente a contradição que a arquitetura existe para 

7# evitar. 

8# 

9# ⚠️ O QUE ESTE MÓDULO CONSERTA. Antes, cada scanner reconhecia o 

10# Controller pelo SUFIXO DO NOME da classe. O sufixo pega o que NÃO é 

11# Controller: a própria regra `RoutesMustPointToController` termina em 

12# "Controller" e era auditada como se fosse um Controller de Planet por 

13# três regras ao mesmo tempo. Ela passava por sorte — não importa nada 

14# da lista proibida da 022, não faz verificação de autenticação e não 

15# manipula arquivo. Bastava um `import hashlib` para virar violação de 

16# uma regra que não tem nada a ver com ela. 

17# 

18# O NOME não basta: o LUGAR diz o que a peça é. Um Controller mora em 

19# `planets/<planeta>/controllers/` — a estrutura que a SOLAR-ARCH-019 

20# já exige de todo Planet. Fora do Planet não há Controller: um 

21# `controller.py` solto em outro diretório tem o nome, mas não tem o 

22# lugar, e é o lugar que a arquitetura usa para saber o que a peça é. 

23from pathlib import Path 

24 

25 

26# Onde os Planetas moram (SOLAR-ARCH-018). 

27PLANETS_DIRECTORY = "planets" 

28 

29# Diretório onde os Controllers de um Planet moram (SOLAR-ARCH-019). 

30CONTROLLERS_DIRECTORY = "controllers" 

31 

32# Segmentos mínimos para caber `planets/<planeta>/controllers/<a>.py`. 

33REQUIRED_SEGMENTS = 4 

34 

35 

36def is_controller_module(file: Path) -> bool: 

37 """ 

38 Indica se o arquivo é um módulo de Controller. 

39 

40 O critério é o LUGAR do arquivo, e não o nome da classe: quem 

41 decide se uma classe é Controller é onde ela foi declarada. 

42 

43 O LUGAR é a estrutura que a SOLAR-ARCH-019 exige de todo Planet: 

44 

45 planets/<planeta>/controllers/<arquivo>.py 

46 

47 Um `controllers/` fora de `planets/` não vale, e um 

48 `controller.py` solto também não: sem o Planet, não há 

49 Controller. 

50 """ 

51 

52 # O diretório imediatamente antes do arquivo é `controllers/`, 

53 # e antes do nome do planeta vem `planets/`. 

54 parts = file.parts 

55 

56 if len(parts) < REQUIRED_SEGMENTS: 

57 return False 

58 

59 return ( 

60 parts[-2] == CONTROLLERS_DIRECTORY 

61 and parts[-4] == PLANETS_DIRECTORY 

62 )
