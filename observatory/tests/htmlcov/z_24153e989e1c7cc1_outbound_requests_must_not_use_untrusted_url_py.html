1# SOLAR-ARCH-030 — SSRF: quem chama não escolhe o destino. 

2# 

3# A regra decide por NOME (`request.names`), e não por fluxo de dados: 

4# sem análise de taint, uma URL "lavada" por várias funções não é 

5# rastreável. Por isso o limite fica documentado no docstring da 

6# classe, e o instrumento para os casos legítimos é o `UrlGuard`. 

7from nucleus.exceptions.solar_exception import SolarException 

8from nucleus.rules.rule import Rule 

9from nucleus.rules.scanner.outbound_request import OutboundRequest 

10 

11 

12class OutboundRequestsMustNotUseUntrustedUrl(Rule): 

13 """ 

14 Regra arquitetural: 

15 

16 SOLAR-ARCH-030 

17 

18 Chamadas a serviços externos NÃO podem usar URL não confiável 

19 (SSRF — Server-Side Request Forgery). 

20 

21 Se quem chama escolhe o destino, ele escolhe o que a 

22 aplicação acessa — inclusive a rede interna: 

23 

24 # requisição maliciosa 

25 GET /preview?url=http://169.254.169.254/latest/meta-data/ 

26 

27 requests.get(request.args["url"]) ❌ credenciais 

28 da instância 

29 httpx.get(f"http://{host}/health") ❌ rede interna 

30 requests.get(url) ❌ o que vier 

31 

32 É VIOLAÇÃO: 

33 

34 requests.get(request.args["url"]) ❌ 

35 httpx.get(f"http://{host}/internal") ❌ 

36 requests.get(callback_url) ❌ 

37 session.get(self.next_url) ❌ 

38 

39 Correto: 

40 

41 requests.get("https://api.exemplo.com/users") ✅ 

42 requests.get(f"{BASE_URL}/users") ✅ 

43 requests.get(environment.get("API_URL")) ✅ 

44 

45 O critério é o ORIGEM da URL, pela convenção do projeto: 

46 

47 CONSTANTE identificador em UPPER_CASE (API_URL, 

48 BASE_URL) — o valor foi decidido no código; 

49 CONFIGURAÇÃO nomes do vocabulário CONFIGURATION_NAMES 

50 (environment, settings, config...) — o valor 

51 foi decidido na configuração. 

52 

53 Qualquer outro identificador que componha a URL é tratado 

54 como NÃO confiável. 

55 

56 Para os casos que precisam mesmo variar em tempo de execução, 

57 o instrumento é `nucleus.security.url_guard.UrlGuard`, que 

58 restringe esquema, host e endereços internos antes da chamada. 

59 

60 Limitação documentada: a decisão é por NOME, não por fluxo de 

61 dados — sem análise de taint, uma URL "lavada" por várias 

62 funções não é rastreável. 

63 

64 O contexto desta regra é um OutboundRequest. 

65 """ 

66 

67 # Vocabulário de ORIGEM DE CONFIGURAÇÃO. 

68 CONFIGURATION_NAMES = frozenset({ 

69 "conf", 

70 "config", 

71 "configuration", 

72 "environ", 

73 "environment", 

74 "getenv", 

75 "settings", 

76 }) 

77 

78 def code(self) -> str: 

79 return "SOLAR-ARCH-030" 

80 

81 def description(self) -> str: 

82 return ( 

83 "Chamadas a serviços externos não podem usar URL não " 

84 "confiável (SSRF)." 

85 ) 

86 

87 def validate(self, request: OutboundRequest) -> None: 

88 

89 # Recolhe TODOS os nomes não confiáveis: uma chamada com dois 

90 # identificadores suspeitos é reportada uma vez só, com os 

91 # dois na mensagem. 

92 untrusted = self._untrusted(request) 

93 

94 if not untrusted: 

95 return 

96 

97 raise SolarException( 

98 self._build_message(request, untrusted) 

99 ) 

100 

101 def _untrusted(self, request: OutboundRequest) -> list[str]: 

102 

103 # `sorted` porque `names` é conjunto: sem ordem fixa, o mesmo 

104 # achado sairia com os nomes trocados de posição a cada 

105 # execução. 

106 return sorted( 

107 name 

108 for name in request.names 

109 if not self._is_trusted(name) 

110 ) 

111 

112 def _is_trusted(self, name: str) -> bool: 

113 """ 

114 Indica se o identificador é origem confiável de URL. 

115 """ 

116 

117 # Constante: pela convenção do projeto, UPPER_CASE. 

118 # `len(name) > 1` descarta o nome de UMA letra só — que 

119 # `isupper()` aceitaria sem ser constante nenhuma. 

120 if len(name) > 1 and name.isupper(): 

121 return True 

122 

123 # Configuração: comparação em minúsculas, porque `Environment` 

124 # e `environment` são o mesmo vocabulário para quem lê. 

125 return name.lower() in self.CONFIGURATION_NAMES 

126 

127 def _build_message( 

128 self, 

129 request: OutboundRequest, 

130 untrusted: list[str] 

131 ) -> str: 

132 

133 names = ", ".join(f"'{name}'" for name in untrusted) 

134 

135 return ( 

136 f"{self.code()}: {request.package} recebe URL montada " 

137 f"com {names} em {request.file}:{request.line}. " 

138 f"Uma URL escolhida por quem chama permite alcançar a " 

139 f"rede interna. Use constante, configuração ou valide " 

140 f"com UrlGuard antes da chamada." 

141 )
